## 1. QQQ: narrow the mechanism, test the consequence, close the research issue

The frozen fiscal-year return to September 2009 is 9.183065%, compared with an issuer-reported 8.41%. This is a convention difference, not an instruction to adjust a particular return until it agrees.

## 2. Execution: actual observations, explicit clock, separate eras
